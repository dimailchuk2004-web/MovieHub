
# Робочі нотатки

## ЛР 2 — Модель предметної області

- Id має тип int, оскільки є числовим ідентифікатором.
- Title має тип string, оскільки зберігає назву фільму.
- ReleaseDate і AddedOn мають тип DateOnly, оскільки зберігають дати без часу.
- DurationMinutes має тип int, оскільки тривалість вимірюється цілими хвилинами.
- Rating має тип decimal?, оскільки рейтинг може бути відсутнім.
- Description має тип string?, оскільки опис не є обов'язковим.
- MovieStatus створено як enum, щоб обмежити можливі стани фільму.


## ЛР 3 — Контекст даних і перша міграція

- Контекст називається MovieHubContext, таблиця Movies, база moviehub.db (SQLite).
- Перетворення decimal на double потрібне для Rating, бо SQLite не має власного типу для десяткових дробів і зберігає decimal текстом, через що сортування й підсумовування працювали б неправильно.
- Фабрику контекстів (AddDbContextFactory) використано замість AddDbContext, бо генератор сторінок у ЛР 4 очікує саме фабрику.
- Міграція Init створена командою dotnet ef migrations add Init і застосована командою dotnet ef database update.
