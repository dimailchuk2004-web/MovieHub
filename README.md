
# MovieHub

Тема: облік фільмів та їхніх прем'єр.

MovieHub обліковує фільми та дати їхніх прем'єр. Застосунок призначений для кіноглядачів, які хочуть стежити за новинками кіно.

## Особливість проєкту

MovieHub матиме календар кінопрем'єр за місяцями.
Користувач зможе переглядати майбутні прем'єри,
фільтрувати фільми за жанрами та переглядати їхні
дати виходу. Це допоможе зручно стежити за новинками
кіно та планувати перегляд фільмів.
